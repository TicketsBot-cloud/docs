# Premium and Whitelabel Perks

---

Premium features are configured in different places across the dashboard. Colour Scheme is found under [Server Settings](/dashboard/settings/settings). Auto Close, Exit Surveys, Awaiting Response Category, and Support Hours are configured per panel in the [panel editor](/dashboard/ticket-panels). Analytics is accessible from the [Analytics](/dashboard/analytics) page in the sidebar.
